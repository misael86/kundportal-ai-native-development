# IssueCard

**Typ:** ärendefeature-komponent
**Storybook:** ja

## Krav — funktionella (K)

- **K1 — Rubrik:** visar ärendets rubrik. **Verifiering:** Automatiserad.
- **K2 — Kategori:** visar ärendets kategori. **Verifiering:** Automatiserad.
- **K3 — Prioritet:** visar ärendets prioritet. **Verifiering:** Automatiserad.
- **K4 — Status:** visar ärendets aktuella status. **Verifiering:** Automatiserad.
- **K5 — Skapelsetid:** visar när ärendet skapades. **Verifiering:** Automatiserad.

## Krav — tillgänglighet (T)

- **T1 — Länk till detalj:** ärendekortet ger en länk till motsvarande ärendedetalj. **Verifiering:** Automatiserad.
- **T2 — Länknamn:** länkens tillgängliga namn identifierar ärendet. **Verifiering:** Automatiserad.
- **T3 — Tangentbord:** länken kan fokuseras och aktiveras med tangentbord. **Verifiering:** Automatiserad.
- **T4 — Touchmål:** länkens aktiveringsyta är minst 44 × 44 CSS-pixlar. **Verifiering:** Automatiserad.
- **T5 — Status utan färg:** status identifieras med text, inte enbart färg. **Verifiering:** Automatiserad.
