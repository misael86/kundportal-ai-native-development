# IssueCard

**Typ:** ärendefeature-komponent
**Storybook:** ja

## Krav — funktionella (K)

- **K1 — Rubrik:** visar ärendets rubrik.
- **K2 — Kategori:** visar ärendets kategori.
- **K3 — Prioritet:** visar ärendets prioritet.
- **K4 — Status:** visar ärendets aktuella status.
- **K5 — Skapelsetid:** visar när ärendet skapades.

## Krav — tillgänglighet (T)

- **T1 — Länk till detalj:** ärendekortet ger en länk till motsvarande ärendedetalj.
- **T2 — Länknamn:** länkens tillgängliga namn identifierar ärendet.
- **T3 — Tangentbord:** länken kan fokuseras och aktiveras med tangentbord.
- **T4 — Touchmål:** länkens aktiveringsyta är minst 44 × 44 CSS-pixlar.
- **T5 — Status utan färg:** status identifieras med text, inte enbart färg.
