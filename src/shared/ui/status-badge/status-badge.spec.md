# StatusBadge

**Typ:** gemensam UI-komponent
**Storybook:** ja

## Krav — funktionella (K)

- **K1 — Statusvärde:** visar en av statusarna Nytt, Pågående, Väntar på kund eller Avslutat som text. **Verifiering:** Automatiserad.

## Krav — tillgänglighet (T)

- **T1 — Status utan färg:** status kan identifieras utan färgseende eftersom statusnamnet visas som text. **Verifiering:** Automatiserad.
- **T2 — Kontrast:** statusens text och färgvariant uppfyller tillämpliga kontrastkrav. **Verifiering:** Båda.
