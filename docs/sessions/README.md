## Rules

1. Reconstructed from the session, not a transcript. Say so at the top.
2. Record the decision, the options, why, and where it is now recorded.
3. Do not duplicate an ADR; link it.
4. Never paste secrets or real customer data.
5. Short. The log entry carries the facts; this file carries the reasoning.
