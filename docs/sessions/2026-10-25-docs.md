## Decisions

| Decision | Options | Chosen because | Recorded in |
|---|---|---|---|
| One rule file, adapters on demand | One file per tool / one file plus adapters | Every adapter is a copy that drifts; add one only when a teammate uses that tool | `AGENTS.md`, [ai-tooling.md](../ai-tooling.md) |
| A feature brief before code | AC only / brief + AC | A brief is checkable by the reviewer and reusable by the agent | `AGENTS.md` §4.2, [features/README.md](../features/README.md) |

| The log is one file per person | One shared file | Four people appending to one file conflict on every merge | [ai-log.md](../ai-log.md) |
